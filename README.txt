VISACROP — PAS FOTO VISA OFFLINE
=================================

Cara termudah di komputer:
1. Buka file index.html dengan browser Chrome, Edge, Firefox, atau Safari.
2. Pilih foto, geser dan perbesar di area potong.
3. Ukuran awal 300 x 369 piksel. Jika berbeda, pilih preset atau isi ukuran manual.
4. Klik "Buat & Unduh Pas Foto". Hasil disimpan pada perangkat, tanpa unggah ke server.

Cara menggunakan di iPhone sebagai aplikasi layar utama (PWA):
1. Unggah seluruh isi folder ZIP (bukan ZIP-nya saja) ke repositori GitHub.
2. Aktifkan Settings > Pages > Deploy from a branch > main / root.
3. Buka alamat GitHub Pages melalui Safari.
4. Tekan Bagikan > Tambahkan ke Layar Utama.
5. Setelah halaman pertama kali dibuka secara online, aplikasi mendukung penggunaan offline.

Catatan penting:
- Aplikasi memotong, memutar 90 derajat, dan menskalakan; tidak mengubah wajah atau mengganti latar.
- Ukuran 300 x 369 px bukan 2 x 2 inci. Untuk 2 x 2 inci pada 300 DPI, pilih 600 x 600 px.
- Tiap negara dan portal bisa memiliki persyaratan yang berbeda: periksa dimensi, ukuran berkas, warna latar, kepala, dan format akhir.
- Foto tidak dikirim ke server; pemrosesan dilakukan di browser pada perangkat.

Catatan versi 1.1: Kontrol pilih foto diganti menjadi input file asli yang menutupi tombol (lebih kompatibel dengan Safari iPhone), dan pembaca gambar memiliki cadangan FileReader. Jika menekan tombol dari penampil lampiran ChatGPT/Quick Look tidak memunculkan pemilih foto, gunakan GitHub Pages lewat Safari.
